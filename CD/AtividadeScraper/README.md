# Atividades de Web Scraping

## Requisitos

- Node.js 18 ou superior

## Instalação

```bash
npm install
```

## Como rodar

```bash
node 1-sucupira.js                  # gera sucupira.csv (500 cursos da Sucupira)
node 2-dois-sites-csv.js            # gera livros.csv e frases.csv
node 3-xkcd.js                      # baixa todas as tirinhas do XKCD na pasta xkcd/
node 3-xkcd.js 10                   # baixa só as 10 tirinhas mais recentes
node 4-cursos-fundacao-bradesco.js  # gera cursos.json (cursos da Fundação Bradesco)
```
